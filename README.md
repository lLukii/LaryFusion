# LaryFusion: A Unified Multimodal Deep Learning Framework for Non-Invasive Laryngeal Cancer Diagnosis
### Data Science Distinction, 2026 S.T. Yau Science Competition Submission
### Abstract: 
Laryngeal cancer is traditionally diagnosed using advanced clinical methods, which are both uncomfortable and inaccessible to patients with limited access to healthcare. Recently, using machine learning (ML) based methods to classify voice data has been considered a friendly and economically sustainable alternative for laryngeal cancer diagnosis. However, existing models suffer from data limitations, such as class imbalance and ambiguity, and are susceptible to background noise, making them hard to train and validate in practice. Additionally, many previous works treat feature extraction and training separately, limiting their model's understanding of domain-specific knowledge. In this paper, we introduce LaryFusion, a fully end-to-end multimodal deep learning framework that diagnoses laryngeal cancer under severe data constraints. Our model leverages demographic/symptom and audio data to mitigate class ambiguity and combines them using a gating network. Furthermore, we employ data augmentation and train the model using focal loss to tackle class imbalance and improve generalization. Evaluating our model on the Far Eastern Memorial Hospital dataset, we achieve a balanced accuracy score of 84.2\%, outperforming all baselines we tested. Overall, LaryFusion illustrates the potential of an end-to-end trained deep learning framework for laryngeal cancer screening.

### Usage
This repository consists of the relevant data and code used to create this project. To run the experiments for yourself, use `inference.py` to test the model on a custom recording, and `train.py` to train/fine-tune a model. To run the Support Vector Machine (SVM) baseline, use `baseline.py` instead. Any hyperparameter tuning should be done in `config.py`.
